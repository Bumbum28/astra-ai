# Sprint 2 patch 2

Fixes an async SQLAlchemy `MissingGreenlet` raised when serializing `User.updated_at` after login.

## Root cause

`TimestampMixin.updated_at` uses `onupdate=func.now()`. SQLAlchemy expires values generated by SQL expressions after an UPDATE unless mapper eager defaults are enabled. Accessing that expired attribute through Pydantic caused an implicit async database read outside SQLAlchemy's greenlet context.

## Changes

- Enable `eager_defaults` on `BaseEntity`.
- Build authentication response DTOs after `flush()` and before `commit()`.
- Add a regression test for the mapper setting.
