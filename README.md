# Astra AI Platform — Sprint 6

Production-oriented AI roleplay/chat platform. This package includes Sprints 1–6.

Sprint 6 builds on Sprint 5 with RAG and provider-independent Tool Calling. Agent Runtime is intentionally deferred to Sprint 7.

See `docs/sprint-06-rag-tool-calling.md` and `docs/ROADMAP.md`.

## Start
```bash
docker compose up --build
```
Frontend lives in `frontend/`. Secrets belong only in local `.env`; this archive does not include `.env`.
