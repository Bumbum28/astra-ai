# Superseded Sprint 5.5 tests

These tests belong to the earlier pre-revision Sprint 5.5 architecture (versioned roleplay profiles, relationship runtime, embedding/compaction memory pipeline, and the experimental intelligence pipeline).

Sprint 5 and Sprint 6 were later revised around the simpler Character/Persona/Memory `ContextAssembler` plus RAG/Tool Calling architecture. The old tests are preserved here for historical reference but are intentionally outside `backend/app/tests`, so they are not part of the active quality gate.

Do not re-enable them without first porting their contracts to the current domain model. Git history remains the authoritative source for the original implementation.
